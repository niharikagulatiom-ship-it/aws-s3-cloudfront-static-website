# AWS Static Website Hosting using Amazon S3 and CloudFront

Successfully deployed a static website using **Amazon S3 and Amazon CloudFront**.

This project demonstrates how to host static website content securely on Amazon S3 and distribute it globally through CloudFront CDN for faster and more reliable content delivery.

**AWS Services Used:**
- Amazon S3
- Amazon CloudFront
- CloudFront Origin Access Control (OAC)
- S3 Bucket Policy

**Key Implementations:**
- Created and configured an S3 bucket.
- Uploaded static website files.
- Configured a CloudFront distribution.
- Integrated S3 with CloudFront using Origin Access Control (OAC).
- Configured bucket permissions for secure access.
- Deployed and tested the live website.

**Live Website:** https://d2r24frcwm8bk.cloudfront.net

**Skills Demonstrated:** AWS S3, CloudFront, CDN, IAM permissions, Bucket Policies, and Cloud Security Basics.
